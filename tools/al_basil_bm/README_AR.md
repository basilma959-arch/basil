# AL BASIL BM — الاستيراد والتصدير

## الطريقة الموصى بها

للحفاظ على تصميم وخصائص تطبيق الأمين كما هي بدون إضافة قارئ Excel داخل التطبيق، اعتمد المسار التالي:

**Excel XLSX → XML متوافق مع الأمين → استيراد إلى AL BASIL BM**

وعند إخراج البيانات:

**XML من AL BASIL BM → XLSX للمراجعة أو التعديل في Excel**

## لماذا XML هو التنسيق الأساسي الأفضل؟

- يطابق بنية تبادل المواد المستخدمة مع تطبيق الأمين.
- يحافظ على أكواد المواد والمجموعات والباركود والوحدة وعوامل التحويل.
- يتجنب مشاكل CSV في الترميز والفواصل واللغة العربية.
- لا يتطلب أي تعديل في خصائص التطبيق الأصلية.

## تجهيز Excel للاستيراد

احفظ الملف بصيغة **Excel Workbook (*.xlsx)**، واجعل الصف الأول يحتوي على:

- اسم الصنف
- رمز الصنف
- اسم المجموعة
- رمز المجموعة — اختياري
- الوحدة
- الكمية — اختياري
- اخر شراء
- رمز الباركود
- عامل تحويل الوحدة الثانية — اختياري
- عامل تحويل الوحدة الثالثة — اختياري

> عمود **اخر شراء** هو سعر الشراء المعتمد في أداة التحويل.

## XLSX → XML

```bash
python excel_to_ameen_xml.py input.xlsx output.xml
```

ثم انقل `output.xml` إلى الهاتف واستخدم وظيفة الاستيراد الأصلية في التطبيق.

## XML → XLSX

```bash
python ameen_xml_to_excel.py input.xml output.xlsx
```

بعدها افتح `output.xlsx` في Excel للمراجعة أو التعديل.

## قاعدة مهمة

احتفظ دائمًا بملف XML الأصلي كنسخة أساسية/احتياطية قبل إجراء أي تعديل على ملف Excel.
